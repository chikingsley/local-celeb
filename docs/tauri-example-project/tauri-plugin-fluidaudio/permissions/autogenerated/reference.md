## Default Permission

Default permissions for the FluidAudio plugin

#### This default permission set includes the following:

- `allow-load-model`
- `allow-unload-model`
- `allow-transcribe-file`
- `allow-transcribe-audio`
- `allow-diarize-file`
- `allow-get-available-models`
- `allow-get-current-model`
- `allow-is-ready`
